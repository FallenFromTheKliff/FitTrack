# Art Direction Review Rubric

## Pass only when all are true

- the scaffold no longer reads like a polished wireframe
- signature elements are visible and coherent
- labels read like product UI, not board notes
- composition feels intentionally premium, not cautiously generic
- the page clearly belongs to the same admin family as sibling premium surfaces
- references are visible in the composition, not only in colors or spacing
- the first-glance silhouette is visibly different from the rejected anti-reference
- the strongest screenshot-backed aesthetic captures are visibly traceable in the result
- the primitive kit no longer reads like generic premium SaaS
- material language and contrast feel intentional, not like a safe default admin kit
- the chosen concept is still visible in the scaffold rather than averaged away

## Hard fail triggers

- annotation or guardrail text inside product frames
- product frames named or labeled like internal board areas
- generic SaaS shell with minor token changes
- safe but bland command surfaces
- over-clean layout with no distinct FitTrack admin identity
- same layout with renamed panels
- same shell with different nouns
- same scaffold with new colors
- same primitive kit with shuffled sections
- support-only product references silently driving the whole visual language
- no first-glance identity from the screenshot alone
