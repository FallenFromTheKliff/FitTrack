# Bad Output Patterns

## Scaffold should fail when it is:

- the same layout with renamed panels
- the same shell with different nouns
- the same scaffold with new colors
- cleaner than before but still visually generic
- structurally better but materially indistinguishable from template SaaS
- impossible to link back to the chosen concept's silhouette or material language

## Reviewer language that should trigger failure

- “this is nicer, but it still feels like a polished wireframe”
- “this looks like the old page with better spacing”
- “I can’t tell what the visual identity is from the screenshot”
- “the workflow is clearer, but the art direction still feels safe”
