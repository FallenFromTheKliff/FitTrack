# Professional UI Consultation Rubric

Use this rubric before route rebuild or scaffold work.

## Required checks

- `Ambition`: does the direction clear the current tier by a visible margin?
- `Operator fit`: does the surface help the real job, not just look cleaner?
- `Component strength`: which major components are genuinely weak or generic?
- `Identity`: does the proposal feel like FitTrack, not a generic admin template?
- `Fixes before enhancements`: are blockers separated from optional polish?
- `Anti-generic pressure`: which stale patterns must be replaced, not preserved?
- `Design thesis`: can the direction be summarized as a distinct product point of view rather than a cleaned-up admin page?
- `Emotional character`: does the page have a memorable mood that still fits operational work?
- `Signature opportunity`: is there at least one visible move that makes the surface feel recognizably FitTrack?

## Premium blockers to call out

- generic list or dashboard composition
- noisy labels or helper text
- safe-but-bland command bars
- weak record or schedule anatomy
- card piles with no hierarchy
- annotation-style copy leaking into UI
- motion used as compensation for weak structure
- recolor-only redesigns where the silhouette and material language stay generic
- reference averaging where good sources are blended into a safe compromise
