# Good Output Patterns

## Strong consultation packet

- clearly separates `workflow fixes` from `visual identity opportunities`
- states one memorable `design thesis`
- uses emotional keywords such as `performance`, `decisive`, `instrument-panel`, `focused`
- names one `signature opportunity` that can be seen in screenshots
- marks weak current UI as `anti_reference`
- recommends a direction that can drive Figma concepting rather than another cleanup pass

## Good signal

The output should make it obvious why the next step is not “polish the current layout” but “design a stronger family with a distinct point of view.”
