# Bad Output Patterns

## Weak consultation packet

- says the UI should be “cleaner” or “more premium” with no design thesis
- recommends better spacing and better typography but no identity shift
- mixes `fixes` and `enhancements` into one generic suggestion list
- treats a clearly weak current page as an adaptation candidate
- references strong products but never says what should actually be borrowed
- produces a route packet that could fit any SaaS admin

## Red flags

- “make it more modern”
- “improve hierarchy”
- “use a dark theme”
- “keep the same layout but refine the cards”
