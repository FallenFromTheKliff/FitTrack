# Modal Surface Template

Every premium modal or drawer packet should include:

- `surface_type`
- `operator_job`
- `open_trigger`
- `default_open_state`
- `edit_state`
- `confirm_state`
- `success_state`
- `error_state`
- `overlay_owner`
- `scroll_owner`
- `escape_and_cancel_behavior`
- `replace_with_page_or_drawer_if_needed`
