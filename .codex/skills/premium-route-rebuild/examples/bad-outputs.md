# Bad Outputs

## Anti-pattern: route rebuild without a real route packet

- "The page needs better spacing and maybe more animation."
- "We can probably improve the table and filters."
- "Add User already looks premium so the route is mostly there."
- "Figma is optional for now."
- "We should probably keep most of the current functions and labels unless they obviously break."

Why this is bad:

- No route verdict
- No route state map
- No keep-replace-remove-add matrix
- No feature inventory
- No operator-first additions
- No required wireframe frames
- No QA gates that separate landing, review, create, and overlays
- It allows another expensive patch pass without changing the workflow
