# Visual DNA Template

Use this packet when defining reusable premium admin art direction.

## Required fields

- `design_thesis`
- `visual_dna`
- `material_language`
- `typography_posture`
- `contrast_and_lighting_model`
- `shape_and_edge_policy`
- `primitive_kit`
- `component_grammar`
- `signature_moves`
- `visual_proof_obligations`
- `disallowed_generic_traits`
- `family_variant_rules`
- `aesthetic_source_ceiling_verdict`
- `aesthetic_synthesis_notes`

## FitTrack default

- baseline identity: `performance_tech`
- meaning: sharp, high-contrast, gym-tech, instrument-panel energy with real operational clarity
- not required:
  - permanent dark mode
  - neon overload
  - gamer UI tropes

## Fail conditions

- the packet can be replaced by "make it cleaner and more premium"
- the direction is only a recolor of a generic admin shell
- the signature moves are too weak to be visible in a screenshot
- the primitive kit still sounds like generic premium SaaS cards and chips
- the packet does not prove which exact screenshot traits must survive into concepting
