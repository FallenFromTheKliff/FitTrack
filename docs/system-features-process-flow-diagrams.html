Web/Admin Activity Diagrams

These module-level activity diagrams summarize management portal behavior from login through each protected page. They intentionally omit visual micro-interactions and confirmation modal details unless they change the outcome.

Admin Staff Protected routes

Web Login and Access Control Admin / Staff

ActorSystemExternal
start-> Enter email and password-> Valid?-> Check lock, OTP, and role gate-> end
Alternative: invalid credentials show an error; locked accounts route to Locked; OTP-required accounts must verify code; non-web roles are redirected to Login.

Dashboard / Portal Landing Admin / Staff

ActorSystemData
start-> Open root or landing route-> Authenticated?-> Redirect to role landing and load portal context-> end
Alternative: unauthenticated users are sent to Login; unauthorized routes fall back to Dashboard or Login.

Analytics and Reports Admin

ActorSystemData
start-> Choose period, metric, or export-> Fetch snapshots, revenue, attendance, members, coaches-> Export?-> Render dashboard or PDF report-> end
Alternative: if data fetch fails, the page shows a recoverable empty/error state and keeps filters available.

Account Module / Members Admin / Staff

ActorSystemExternal
start-> Search member, create account, review payment, or scan QR-> Valid action?-> Update user, attendance, deletion, or payment state-> end
Alternative: duplicate or incomplete user input is rejected; invalid QR falls back to manual entry; rejected payment keeps access blocked.

Gym Operations / Schedule Admin / Staff

ActorSystemPayment
start-> Manage coach, availability, appointment, booking, or recurring plan-> Slot / payment valid?-> Create, update, complete, cancel, or collect payment-> end
Alternative: unavailable slots are rejected; cash payment can be verified by staff; PayMongo opens checkout and waits for final status.

Exercise Lab Admin / Staff

ActorSystemData
start-> Review submission or edit exercise contract-> Approve / update?-> Persist exercise, muscle, pose, or review state-> end
Alternative: invalid exercise metadata remains in review and does not enter the public exercise library.

Gamification Admin Admin

ActorSystemData
start-> Inspect overview, season, creator, ranking, or integrity case-> Governance change?-> Update season, override, creator state, or case outcome-> end
Alternative: staff role cannot access this module; unresolved cases remain open and visible.

BrodigyAI Web Admin / Staff

ActorSystemAI
start-> Select session or send prompt-> Load history and create/update session-> AI available?-> Return answer or fallback error-> end
Alternative: archived sessions can be restored; deleted/failed sessions do not erase unrelated chat history.

Facilities Admin

ActorSystemData
start-> Create, edit, archive, restore amenity or layout equipment-> Has reservations?-> Save layout/media/equipment or block unsafe deletion-> end
Alternative: occupied amenities cannot be deleted without preserving booking integrity.

Inventory Management Admin / Staff

ActorSystemPayment
start-> Manage products, equipment, restock, writeoff, or sale-> Stock sufficient?-> Persist inventory movement and sales summary-> end
Alternative: out-of-stock products cannot complete sale; writeoffs reduce usable equipment quantity.

Settings Admin / Staff

ActorSystemData
start-> Update gym details, appearance, notifications, or security-> Valid settings?-> Persist preferences and apply portal state-> end
Alternative: invalid password/security input is rejected and previous settings remain active.

Profile Settings Admin / Staff

ActorSystemFile
start-> Edit personal details or avatar-> Changed and valid?-> Patch profile and refresh session user-> end
Alternative: canceled edits restore the prior profile values; invalid uploads are not committed.

Mobile/Gym Member Activity Diagrams

These diagrams summarize member application behavior from login, registration, and protected tab navigation through the major gym member modules.

Gym Member Mobile app Member services

Mobile Auth and Registration Gym Member

ActorSystemEmail
start-> Sign in, register, or reset password-> Valid?-> Commit member session or send OTP/reset code-> end
Alternative: non-member portal roles are denied; locked or invalid accounts stay on auth screen.

Home Gym Member

ActorSystemData
start-> Open member home-> Load progress, membership, goals, and quick actions-> Membership active?-> Show available actions or upsell restrictions-> end
Alternative: missing membership limits member-only actions until payment/card state is resolved.

Facilities Gym Member

ActorSystemData
start-> Browse gym floor and facility details-> Load amenities, floor plan, and status-> Bookable?-> Open booking path or show information only-> end
Alternative: archived or unavailable facilities are visible only as inactive or unavailable items.

Bookings Gym Member

ActorSystemPayment
start-> Select date, amenity, coach, and time slot-> Slot available?-> Create booking or appointment and payment request-> end
Alternative: unavailable slots fail validation; pending payments keep bookings from becoming fully settled.

Nutrition Gym Member

ActorSystemData
start-> Calculate targets or log meal-> Complete inputs?-> Save TDEE, macro target, log, and summary-> end
Alternative: incomplete or invalid nutrition inputs block calculation or log creation.

Muscle Mastery Gym Member

ActorSystemData
start-> Open mastery profile or leaderboard-> Load progression, milestones, rankings, and integrity summary-> New progress?-> Display mastery state and earned progress-> end
Alternative: suspicious or unresolved activity can be surfaced through integrity status rather than granting progress silently.

Workout and Pose Session Gym Member

ActorSystemCamera / AI
start-> Choose workout and start session-> Camera ready?-> Analyze pose, count reps, save sets, finalize session-> end
Alternative: camera or pose failure falls back to manual workout review; pending membership can lock live tracking.

BrodigyAI Chat Gym Member

ActorSystemAI
start-> Open chat history or send prompt-> Create/select session and send grounded context-> In scope?-> Return answer, refusal, or error-> end
Alternative: archived chat sessions can be removed from normal history; out-of-scope prompts receive a bounded response.

Profile Gym Member

ActorSystemPayment
start-> View QR, membership, subscription, avatar, or deletion request-> Payment needed?-> Update profile or initiate/await membership payment-> end
Alternative: cancelled checkout leaves membership unchanged; deletion request freezes account state until admin review.

Settings Gym Member

ActorSystemData
start-> Change preferences, password, help, or legal information-> Valid update?-> Persist preference or security update-> end
Alternative: invalid current password or weak new password blocks the change.
