FitTrack is a Windows-based Turborepo monorepo for SertFit Gym with two main apps: apps/mobile (Expo 55, Expo Router, React Native 0.83, React 19, Reanimated 4, TanStack Query 5) for members, and apps/web (Next.js 16 App Router, React 19, Tailwind, TanStack Query 5, framer-motion, Radix UI) for admins/staff. Shared logic lives in packages/* (ui, types, utils, hooks, validators, query). Backend exists in apps/api but is generally frozen except when a task explicitly allows it.
