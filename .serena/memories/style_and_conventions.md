TypeScript strict mode. No any, no suppression comments, no source comments. Compact formatting: no excessive blank lines, no trailing commas, no vertical alignment. Use path aliases. Mobile uses makeXxxStyles(colors) style factories wrapped in useMemo and Reanimated only for animations; prefer Fit components. Web uses CSSProperties style factories for page/layout styles and cn()+Tailwind only inside Fit components; client files requiring hooks/events must start with "use client". Protected context files and additive-only shared package rules are defined in .ai/context-protection.md. Local Prisma schema, migrations, and seeded DB data are development-only: for refactors or feature additions, schema changes are allowed when they are the cleanest fix, as long as the result stays reseed-safe and the change is documented in task evidence. Persistent business data and cross-device workflow state must not live in localStorage/sessionStorage; use Postgres-backed endpoints for source-of-truth data, and reserve browser storage for clearly local UI convenience only.
