# ROM Calibration

## Calibration rules

- Do not use one global ROM threshold across all exercises.
- Calibrate by exercise family first, then by exercise profile.
- Separate:
  - minimum useful travel
  - valid partial rep
  - valid full rep
  - no-count motion

## Verification set

- ideal full reps
- consumer-realistic reps
- partial reps if product policy allows them
- setup and reset motion
- occlusion and low-confidence motion
- off-axis but still valid reps

## Tuning artifact

Every completed tuning pass should be able to summarize:

- exercise and provider
- canonical joints and segments
- minimum travel
- full-rep band
- partial band if allowed
- confidence and visibility rules
- known failure cases
