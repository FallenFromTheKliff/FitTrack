# FitTrack Coupling Map

Use this map to decide whether a feature belongs naturally inside the current product.

## Common FitTrack coupling zones

- onboarding and profile setup
- workout execution and pose flows
- progress and streak tracking
- achievements, XP, and gamification
- memberships, attendance, and gym operations
- admin insights and business analytics
- grounded coaching or AI assistance
- notifications and reminders

## Immediate-coupling rule

- Choose only the couplings that make the feature feel native right away.
- Prefer 1 to 3 immediate couplings.
- Everything else belongs in deferred couplings unless the MVP clearly needs it.

## Coherence checks

- Does the feature reinforce an existing user loop?
- Does it make dashboards, progress, or coaching more meaningful?
- Does it create a believable reward or retention loop?
- Would it still make sense if removed from the rest of FitTrack? If yes, it may be too isolated.
